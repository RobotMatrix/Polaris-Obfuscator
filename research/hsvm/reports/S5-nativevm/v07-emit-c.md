# V-07 原生代码发射 + 真实编译器差分

`include/hsvm/emit_c.h`、`src/emit_c.cpp`、`tests/test_emit.cpp`（ctest `emit_c`，18 条断言）。

链路：字节码 → `lift` → `lowerOp` → **C 源码** → `clang -O1` → 运行 → 与 oracle 期望值比对。
每次比对两样东西：**退出码**和**报告字符串**。

## 三种可观测结局都覆盖了

| 用例 | 结局 | 退出码 | 报告 |
|---|---|---|---|
| `sum0`（sum，初值 0） | 正常停机 | 0 | `r0=0 mem=76efddc5` |
| `memround`（自建 store/load 程序） | 正常停机 | 0 | `r0=287454020 mem=…` |
| `allops_fault` | 地址越界故障 | 3 | `fault` |
| `crc_budget` / `copy_budget` | 超出步数预算 | 5 | `budget` |

`memround` 是专门补的用例：`sum` 从零起跑不写内存，不能证明原生路径真的走过访存。
它 `St` 一个值再 `Ld` 回来，断言 `r0=287454020`（0x11223344），并断言内存摘要
**不等于**全零数组的摘要——否则"存了个 0"也能过。

## 与计划的一处偏离（记录在案）

计划里 V-07 是"发射 LLVM IR 文本"。实际做的是发射 **C**，理由：
手写 `.ll` 语法会引入一个与语义无关的失败来源，而这一片要证明的是"语义经过真实编译器后不变"。
LLVM IR 作为媒介放在 V-08（Polaris pass）里，那里本来就要写 IR。

代价：`clang -O1` 对 C 的优化强度与 Polaris 里的 pass 不同，性能口径不能从这里取。

## 边界

- 已证：五个用例上，原生可执行文件的退出码与报告字符串与 oracle 逐字节一致。
- 未证：`budget`（步数上限）是**发射层**引入的概念，ISA 与解释器里没有，属于本切片的自定界，
  不是语义的一部分；性能；跨平台（只跑过 arm64 macOS）。
- 已证的反面：`sum` 之外的程序在合理预算内不停机，所以"正常停机"只由一个用例覆盖。
