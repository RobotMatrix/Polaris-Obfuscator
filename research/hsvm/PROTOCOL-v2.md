# 实验协议 v2.0（草稿）— C2 先行 / 薄窗口路线

- 状态：**草稿，未执行任何实验**
- 取代：`protocol.json` v1.0（哈希 `f964755d…515c1f`）；v1 的结论与报告保持原样，不用 v2 重判
- 机读版：`protocol-v2.json`；校验：`python3 tools/check_protocol.py protocol-v2.json`

## 为什么要开 v2

v1 在 G1 模型层判失败，原因只有一个：**成本**。登记 48 点全部满足 Γ 与非仿射，
但没有一点达到 `step_cost_ratio ≤ 3`（最好 5.62×，且是 2^8 可枚举的表点）。
ADR-007 的 ARX 补充实验把 ψ 成本减半，最好的"不可枚举"点从 22.1× 降到 10.85×，
瓶颈随之暴露为 **O(w) 的窗口读取**：w=48 时约 48 次位提取，已占单步四成。

所以 v2 不再把 C1 的安全判定压在"w 必须 ≥48"，而是：

1. 允许薄窗口（w≤32），把"不可枚举"重新定义为**在 C2 编码接口上的查询成本**；
2. 把成本门禁从"跑网格找点"改成**先推导下界**（G0v2），下界超限就直接终止，不写 C2 代码；
3. 明确只主张 A2-static；A2-dynamic 的边界写死，不作为门禁失败。

## G0v2：成本下界（第一道门，先于一切实现）

- 基线：`research/hsvm` 的 Plain 模式解释器（16×32 位寄存器、4 KiB 内存、无 trace），
  实测 4.2 ns/指令。**基线不变、口径不变**——这是 v1 就冻结的，v2 不放松。
- 目标：单步 ≤ 3 × 4.2 = **12.6 ns**。
- 方法：解析法（按窗口读取 w、散布 c·r̄、ψ 轮数、v 的 8 字异或、调用/调度逐项计数）
  与实测法（同一宿主上逐项计时）**都做**，取两者较大值。
- 判据：若下界 > 12.6 ns ⇒ 触发 `g0v2_cost_floor_above_cap`，**不实现 C2，路线终止**。
- 预注册预期（原文见 json）：w=8、c=8、r̄=1 的解析下界约 25 个词操作，
  对约 10 个操作的 plain 指令 ≥2.5×；加上任何真实 ψ 后，实测下界预计落在 3–6×。
  **也就是说，本草案自己预期会在 G0v2 终止。**

## 安全门（只在 G0v2 通过后才允许执行）

- 攻击者模型：**A2-static**（有二进制、无运行时秘密）。
- 指标：通过 C2 接口**实际探测**出完整 ψ oracle 所需的查询数，必须 > 2^40；
  该数字必须在 C2 构建上测量，**不得**从无编码模型推断。
- 编码族：逐步仿射、局部支撑；附加 BGE / DCA / 仿射等价攻击，预算 2^32，
  且必须先在校准目标（wbaes 表）上跑通阳性对照。
- 边界（必须写进任何报告）：A2-dynamic 可读运行时编码状态，逐步仿射预计会被
  BGE 类线性代数击穿；v2 不主张该模型下的安全。

## 网格与选点

`w ∈ {8,16,32}`、`c ∈ {8,16}`、`r̄ ∈ {1,2}`、`rounds ∈ {0,2,4}`、`psi ∈ {table,spn,arx}`。
`chosen_point` 仍为 `null`，只有在 G0v2 通过后才允许写入；写入后重算协议哈希。

## 停止规则

1. `g0v2_cost_floor_above_cap`：下界 > 12.6 ns ⇒ 终止路线。
2. `encoded_oracle_below_2pow40_probes`：C2 接口可在 ≤2^40 探测内建出 ψ oracle ⇒ 当前编码族判死。
3. `stage2_whitebox_recovers_psi_or_compact_model`：BGE/DCA 在 2^32 内成功 ⇒ 同 2。
4. `core_hypothesis_success_rate_at_least_0_10`：主假设被直接否证。

## 迁移与口径规则

- v1 报告保留 v1 哈希；v2 报告必须引用 v2 哈希。**两份哈希不得混用**。
- 任何把 v1 数据说成"v2 已通过"的表述都算伪造证据。
- v2 的成本口径与 v1 完全相同（同基线、同指标名 `step_cost_ratio`、同 cap 3.0），
  这样两版结果可以直接比较，而不是换尺子。
- 若 G0v2 未通过，v2 的唯一产出就是一条下界结论；不得进入 C2 实现。
