# 白盒 AES 对外产物（唯一一份）

`wbaes_vm2_max` 的**去符号形态**：同一份代码与表，符号表、导出表、段名、unwind 表全部处理过。

| 文件 | 字节 | sha256 |
|---|---|---|
| `wbaes_vm2_max` | 70,294,736 | `2cc368ff050ad1b24573c09d01a4ac7ed6aa99391fa6b0c277a6a45797788b9b` |

## 这是哪一代

跨 lane 非线性重编码（SPN 三轮、MDS (1,4,3,7)）＋ VM 在装载时一次算完 288 个表偏移。
按**实测的密钥提取成本**选它，不按速度选：

| 代 | 每密钥字节检验次数 | 静态出钥 | 轨迹出钥 | 每块耗时 |
|---|---|---|---|---|
| **本产物（vm2 / nl）** | **16,384** | 18.5 s | 64 条轨迹，~1 s | 16.9 µs |
| f4（16 位部分和） | 4,096 | 0.08 s 代数 | — | 13.4 µs |
| dl4 | 16,384 | 17 s | 0.68 s | 4.5 µs |

f4 更快（−20%）但弱一个量级，按"只发最强"的策略不对外。

## 这一版做了什么硬化

```
strip         删除全部符号（不只是 -x 的本地符号）
scrub         段名随机化、导出表置空、__unwind_info 改写成有效空表
              （否则 unwind 表会以 0.88 的精度点出真实函数起始）
残留检查       macho_symbols.py 全文件 0 命中 WBAES|hsvm|hy_vm|_ZN；
               m1_detect 总分 0（S1..S8 全 0）
未包含        S2/S2b 计算分支（+63~67% 运行时，换可被读表撤销的静态不透明，热路径不划算）
              S4 合并后拆分（merge 只吃 void，白盒核心是 int，强行路由会崩）
```

## 已知强度上限——请勿把它读成"安全"

- 16,384 次一致性检验是**脚本级**成本：笔记本上 18.5 s 出钥；64 条地址轨迹约 1 s 出钥。
- 去符号只增加"第一眼"的成本，不改变表内容——已有实测：硬化前后提取耗时 15.6 s vs 15.3 s。
- 块长 16、9 轮、AES 代数指纹对研究者不可隐藏（`demos/wbaes/FINGERPRINT.md`）。

正确表述：**当前强度最高的一代**，不是"不可攻破"。

## 外部复现（2026-11，独立测量，未采信本仓库脚本）

审阅方在这份**去符号产物本身**上复现了 nl/dl5 结构，数字与本仓库 `attacks/residual/hs_attack.py` 同量级：

```
表段   __DATA,__5gg5earvam（改名后的 70,090,816 B，off 49,344）
掩码   种子 0xb8ab764e，解掩 14.6 s
结构   32 张 pair 表 Q = Z∘(D0⊕D1)，(Z2)^8 正则作用 2097152/2097152 项，Z 在 32/32 表双射
检验   规范不变一致性检验 64 个 (col,lane,row) 位置各 1 候选，MC 四行 16/16 一致
       （把规范当恒等的 dl4 老检验仍是 0 候选）
成本   16,384 次仿射一致性检验 + 32 次群恢复；代数 2.9 s；
       首次含解掩 18.0 s，有缓存 3.4 s；无轨迹、无搜索
```

结论与本仓库一致：**去符号只买到"第一眼"的成本**，不改变表内容；
每密钥字节 ~2^8 次检验是这一代的结构天花板（`demos/wbaes/WB-DESIGN-V2.md` §十四）。
